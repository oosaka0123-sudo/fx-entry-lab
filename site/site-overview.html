ABOUT THIS SITE

サイト概要

FX Entry Labは、GBPJPYのショート候補を対象に、右肩戻り売りロジックの監視・研究・通知を行う独立検証サイトです。

目的

相場判断の流れを、上位足下降 → 推進 → 最初の戻し → 右肩 → DMAトリガー → 通知候補という順序で整理し、再現可能な形で検証します。

  • 対象通貨：GBPJPY
  • 使用時間足：D1 / H4 / H1 / M15 / M5
  • TRIGGERは通知候補であり、注文ではありません
  • 実注文・自動売買は行いません
  • orders_enabled: false を維持します
